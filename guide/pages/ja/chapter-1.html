第1章. ローカル/リモートリポジトリの定義

リポジトリは、作業の記録を保管する 記録保存先です。 記録保存先は、まず 2 種類に分けて考えるとわかりやすくなります。

  • ローカルリポジトリ: 自分のパソコンの中にある記録保存先
  • リモートリポジトリ: インターネット上のどこかにある記録保存先

大事なのは、Git と GitHub は同じ意味ではないということです。 Git は記録を扱うシステムで、GitHub はそのリモート記録保存先を置いておくサービスのひとつです。 （Bitbucket のようなサービスもあります。）

実務では、ローカル側でリモート記録保存先の名前をふつう origin にしておくことが多いです。 そのため origin/main のような表現をよく見られます。

もうひとつ重要なのは、ローカルとリモートが 常に自動で同じ動きをするわけではない という点です。 互いに独立した記録保存先なので、自分で送るか受け取るかしない限り内容はそろいません。

ローカルの記録はどこに保存されるのか

ローカルリポジトリの中核となる記録は、プロジェクトフォルダ内の .git フォルダに保存されます。 このフォルダがあれば、「このフォルダは Git の記録保存先だ」と考えることができます。

my-project/
.git/ ← Git の記録（履歴、ブランチ情報など）
art/
ui/
